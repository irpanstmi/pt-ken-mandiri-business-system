# PT Ken Mandiri Business Information System

## About the Project
A web-based business information system developed to support business operations and data management at PT Ken Mandiri. The application helps manage product data, customer information, supplier records, sales invoices, and purchase receipts.

## Features
- Product data management
- Customer data management
- Supplier data management
- Sales invoice management
- Purchase receipt management

## Technologies Used
- PHP
- MySQL
- HTML & CSS
- XAMPP

## Installation and Setup
1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Move the project folder into the `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Create a MySQL database and import the provided SQL file, if available.
6. Configure the database connection in the project configuration file.
7. Open the application in your browser through `http://localhost/your-project-folder`.

## Project Purpose
This project was developed as part of a Database Management course to apply web development and database management concepts in a practical business scenario.
